## Vendored Google Fonts

`public/fonts/google` contains an intentionally curated cache of unmodified font binaries from
Google Fonts. Every family directory includes its upstream `OFL.txt` and `METADATA.pb` files. The
generated `manifest.json` records the exact Google Fonts repository commit, Web Fonts Developer
API version metadata, source URL, size and SHA-256 digest for each copied file. The generated
`curated.css` is not imported by the editor yet.

These fonts are licensed under the SIL Open Font License, Version 1.1. Font copyright statements,
authors, designers and any Reserved Font Names are retained in the adjacent license and metadata
files. Frontend Lib does not modify or claim ownership of the vendored font software.
